# Software Engineering Methods (ENUIC) - Agile & DevOps Project

This repository documents the structural engineering, development workflows, and agile task management strategies implemented for the **Software Engineering Methods** course module.

##  Project Overview
The core objective of this project is to demonstrate advanced software development lifecycles (SDLC) by integrating rigorous **Agile project management** with automated **DevOps workflows**. The project is structured around a C# application, verified and refined across sequential checkpoint evaluations.

---

##  Project Architecture & DevOps Integration

###  Code Review 1 Implementation (Foundation & CI/CD)
* **Project Builds:** Configured the application utilizing `.NET CLI` / `MSBuild` tools to ensure clean compilation into self-contained executable/DLL layers.
* **Continuous Integration (CI):** Fully implemented automated execution via **GitHub Actions** workflows to manage structural building blocks and integrity checks upon every push event.
* **GitFlow Branching Strategy:** Enforced strict version control isolation with dedicated `master`, `develop`, and structural feature/release branches.
* **Project Standards:** Established a comprehensive `Code of Conduct` to govern team cooperation frameworks and deployed the `First Release` milestone branch.

###  Code Review 2 Implementation (Agile & Requirements Gathering)
* **Issue Tracking & Requirements:** Utilized **GitHub Issues** mapped directly against feature milestones, technical bugs, and tasks.
* **User Stories & Use Cases:** Requirements were structured from end-user perspectives, detailing complete execution pre-conditions, interaction triggers, and dynamic operational loops.
* **Visual Modelling:** Integrated complete **Use Case Diagrams** and **Activity Diagrams** to thoroughly trace system boundary behaviors and actor dynamics.
* **Kanban Workflow Board:** Linked the codebase with **Zube.io integration** to maintain real-time tracking from sprint backlog priorities down to functional deployment.
